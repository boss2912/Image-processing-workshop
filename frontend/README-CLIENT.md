# เครื่องผู้ใช้ (Client) — วิธีรัน

โฟลเดอร์นี้คือ**ทั้งหมด**ที่เครื่องผู้ใช้ต้องมี คัดลอกทั้งโฟลเดอร์ไปเครื่องอีกเครื่องได้เลย

```
frontend/
├── index.html          หน้าเว็บ
├── app.js              โค้ดที่คุยกับ backend
├── style.css           หน้าตา
├── start-client.bat    ดับเบิลคลิกเพื่อรัน
└── README-CLIENT.md    ไฟล์นี้
```

**ไม่ต้องติดตั้งอะไรเลย** ไม่ต้องมี Flask ไม่ต้องมี OpenCV ไม่ต้องมี venv
ขอแค่มี **Python** กับ **Chrome** — เพราะเครื่องนี้ไม่ได้ประมวลผลภาพ มันแค่ส่งภาพไปให้เครื่องเซิร์ฟเวอร์แล้วรอรับภาพกลับมา

---

## วิธีที่ 1 — ดับเบิลคลิก (ง่ายสุด สำหรับเพื่อน)

ดับเบิลคลิก **`start-client.bat`** แล้วข้ามไปอ่านหัวข้อ "บอกหน้าเว็บว่าเซิร์ฟเวอร์อยู่ที่ไหน"

---

## วิธีที่ 2 — รันจาก VS Code Terminal

กด **Ctrl + `** เปิด terminal แล้วทำทีละคำสั่ง

### คำสั่งที่ 1 — เข้าโฟลเดอร์นี้

**วิธีที่ง่ายที่สุด**: ใน VS Code เลือก **File → Open Folder** แล้วเลือกโฟลเดอร์ที่แตก zip ไว้
พอเปิด terminal (**Ctrl + `**) มันจะอยู่ในโฟลเดอร์นี้ให้เองอยู่แล้ว ไม่ต้อง `cd`

ถ้าอยาก `cd` เอง ให้ใส่ path ที่**แตก zip ไว้บนเครื่องตัวเอง** เช่น

```powershell
cd "$env:USERPROFILE\Downloads\Image-Processing-Client"
```

เช็คว่าอยู่ถูกที่ — ต้องเห็น `index.html`
```powershell
dir
```

### คำสั่งที่ 2 — เปิดเว็บเซิร์ฟเวอร์

```powershell
python -m http.server 8000
```

ต้องเห็น
```
Serving HTTP on :: port 8000 (http://[::]:8000/) ...
```

**ปล่อยหน้าต่างนี้เปิดค้างไว้** กด `Ctrl + C` เมื่อจะหยุด

> ไม่ต้องมี `.venv` ไม่ต้อง `pip install` อะไรเลย เพราะ `http.server` เป็นของที่ติดมากับ Python อยู่แล้ว
> และหน้าเว็บนี้ไม่ได้ใช้ไลบรารีภายนอกสักตัว

### คำสั่งที่ 3 — เปิดเบราว์เซอร์

เปิด terminal **อีกหน้าต่าง** (กด `+`) แล้ว

```powershell
Start-Process "http://localhost:8000"
```

หรือพิมพ์ `http://localhost:8000` ในเบราว์เซอร์เอง

> **ห้ามเปิด `index.html` ด้วยการดับเบิลคลิกไฟล์ตรงๆ** จะได้ URL ขึ้นต้นด้วย `file://`
> ซึ่งเบราว์เซอร์จะบล็อก request ข้ามไปหา backend ทันที (CORS ไม่ยอมให้ origin เป็น `null`)
> ต้องเปิดผ่าน `http://localhost:8000` เท่านั้น

### ทดสอบว่าเสิร์ฟไฟล์ได้จริง

เปิด terminal อีกอันแล้ว
```powershell
curl.exe -I http://localhost:8000/index.html
```
ต้องได้ `HTTP/1.0 200 OK`

> ต้องพิมพ์ `curl.exe` ไม่ใช่ `curl` เฉยๆ เพราะใน PowerShell `curl` เป็นชื่อเล่นของ `Invoke-WebRequest`

## บอกหน้าเว็บว่าเซิร์ฟเวอร์อยู่ที่ไหน

ในช่อง **Backend URL** ใส่ IP ของ**เครื่องเซิร์ฟเวอร์** ตามด้วย `:5000`

```
http://172.20.56.133:5000
```

> IP ตัวนี้เอามาจากเครื่องเซิร์ฟเวอร์ ไม่ใช่เครื่องนี้
> คนที่นั่งเครื่องเซิร์ฟเวอร์รัน `ipconfig` แล้วดูบรรทัด **IPv4 Address** แล้วบอกมา

กด **เชื่อมต่อ** ถ้าขึ้นข้อความสีเขียวว่า `เชื่อมต่อสำเร็จ: Image Processing Backend (5 operations)` แปลว่าใช้ได้

> **ทดสอบบนเครื่องเดียวก่อนได้** ถ้ารัน backend กับ frontend บนเครื่องเดียวกัน
> ให้ใส่ `http://127.0.0.1:5000` ซึ่งเป็นค่าตั้งต้นอยู่แล้ว หน้าเว็บจะเชื่อมต่อให้เองตอนเปิด
> ผ่านแล้วค่อยเปลี่ยนเป็น IP จริงตอนแยกเครื่อง

### ใช้งาน

เลือก operation → เลือกไฟล์ภาพ → กด **ประมวลผล**
ภาพซ้ายคือต้นฉบับในเครื่องนี้ ภาพขวาคือผลลัพธ์ที่**เครื่องเซิร์ฟเวอร์**ประมวลผลแล้วส่งกลับมา

## ต่อไม่ติด — ไล่ตามลำดับนี้

**ทดสอบก่อนว่าถึงกันไหม** เปิด PowerShell บนเครื่องผู้ใช้:

```powershell
ping 172.20.56.133
```

| ผลที่ได้ | แปลว่า | ต้องแก้ที่ |
|---|---|---|
| ping ไม่ผ่าน | สองเครื่องคุยกันไม่ได้เลย | ดูข้อ A |
| ping ผ่าน แต่หน้าเว็บต่อไม่ติด | Firewall ของเครื่องเซิร์ฟเวอร์บล็อกพอร์ต 5000 | ดูข้อ B |

### A. ping ไม่ผ่าน

1. เช็คว่าทั้งสองเครื่องต่อ Wi-Fi **ชื่อเดียวกัน**
2. ถ้าเป็น Wi-Fi ของสถานศึกษา (เช่น `CDTI_STUDENT`) มักเปิด **AP isolation** ไว้
   คือกันไม่ให้เครื่องในวงเดียวกันคุยกัน — **แก้ที่เครื่องเราไม่ได้เลย**
   **ทางออก: เปิดฮอตสปอตจากมือถือ แล้วให้ทั้งสองเครื่องต่อฮอตสปอตนั้น**

### B. ping ผ่าน แต่ต่อไม่ติด

ให้คนที่เครื่องเซิร์ฟเวอร์เปิด PowerShell แบบ **Run as Administrator** แล้วรัน:

```powershell
New-NetFirewallRule -DisplayName "Image Processing Backend 5000" -Direction Inbound -LocalPort 5000 -Protocol TCP -Action Allow -Profile Any
```

ทดสอบซ้ำจากเครื่องผู้ใช้:

```powershell
curl http://172.20.56.133:5000/api/health
```

ถ้าได้ `{"service":"Image Processing Backend","status":"ok"}` แปลว่าผ่านแล้ว

### C. หน้าเว็บขึ้น error สีแดงว่าเชื่อมต่อไม่ได้ ทั้งที่ curl ผ่าน

เป็นเรื่อง CORS — เช็คที่เครื่องเซิร์ฟเวอร์ว่าติดตั้ง `flask-cors` แล้วจริง:

```powershell
pip list | findstr /i flask-cors
```
